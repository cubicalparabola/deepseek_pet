# 鲸鱼娘桌宠（Desktop Pet）

一只住在 Windows 桌面上的**鲸鱼娘**：透明无边框、始终置顶、会自己动、能聊天、有心情与饱腹度、
记得住事、会看你屏幕在做什么并有节制地开口。AI 认知、环境感知、成长反思、插件四块都能单独关掉。

`Electron 33` + `TypeScript`，渲染层是原生 DOM（无前端框架）；28 条动画全部由清单驱动。

---

## 1. 这是什么

| 模块 | 做什么 |
| --- | --- |
| **宠物本体** | 28 条动画（状态 / 随机 / 触发 / 点击四类）、三段式播放、点击不可打断、贴边收起与就地展开、隐藏、透明无边框置顶窗口、20%~250% 缩放 |
| **鼠标互动** | 左键点击（随机一条点击反应）、双击、右键菜单、拖拽换位置、鼠标从下方/右侧靠近时"接住" |
| **对话气泡** | 她说短句时在头顶弹气泡（可滚动正文 + 「知道了」按钮），窗口临时撑大，气泡消失后收回 |
| **AI 认知与人格** | 接任意 OpenAI 兼容端点聊天；四层记忆；心情 + 饱腹两个内部状态并注入提示词；每天写日记；主动闲聊；把统计出来的习惯归纳成"她眼里的你"；可调用 `recall_memory` 按需检索记忆宫殿 |
| **环境与用户感知** | 周期性截图做**场景分类**；读地址栏与窗口上下文；观察空闲 / 连续使用 / 切换频率 / 深夜；摄像头（需授权）判断在不在、表情、久坐、陌生人；生成"今天在做什么"的时间线；六层习惯学习；隐私模式一键停 |
| **成长、记忆与反思** | 重要经历组成**记忆宫殿**（面板可视化 + `palace.md`）；每天自我反思并产出一个**只会让她更安静**的策略叠加层 |
| **交互收件箱** | 她保存重要事情的地方：主题 + 正文 + 附件，已读未读，插件也可以往里投递（类似邮件） |
| **插件系统** | 按权限声明的能力扩展：装 / 卸 / 随时启停；插件能在托盘菜单加动作、在聊天窗口加页签、发系统通知、投递收件箱 |
| **数据与隐私** | 记忆 / 日记 / 小纸条 / 感知明细默认放在**项目目录的 `data/`**；截图与摄像头帧永不落盘；渲染进程拿不到密钥、也不能联网 |

## 2. 快速开始

```bash
npm install
npm start                # 构建 + 启动桌宠
```

其他常用命令：

```bash
npm run dev              # 开发模式启动
npm run typecheck        # tsc --noEmit
npm run build            # 类型检查 + 打包主进程 / 渲染层 / 设置窗口 / 聊天窗口 / 插件 + 拷贝静态资源
npm run pack             # 打包成未安装目录（快速验证）
npm run dist             # 生成 Windows NSIS 安装包
npm run logs             # 实时查看日志
npm run acceptance       # 端到端验收（391 项检查，真实启动桌宠；跑完自动还原你的设置）
npm run icons            # 从 assets/brand/ds.png 生成应用与托盘图标
npm run convert:alpha    # 把黑底素材烘焙成带 alpha 的透明 WebM（需要 ffmpeg）
```

启动后：桌宠出现在主屏右下角，透明、无边框、始终置顶；在托盘图标或她身上右键都能出菜单。

## 3. 怎么用

### 3.1 桌宠本身

| 操作 | 结果 |
| --- | --- |
| 左键点一下 | 演一条点击反应（`cute` / `fawning` / `stroke` 随机，避开正在冷却的那条），心情 +5 |
| 双击 | 算一次互动（心情 +7），不放动画 |
| 右键 | 弹出菜单（与托盘菜单同一份） |
| 按住拖动 | 移动位置（位移超过 5px 才算拖动；窗口位置对齐物理像素网格） |
| 鼠标靠近下方 / 右侧 150px 内 | 演 `catch_down` / `catch_right`（两次之间至少隔 60 秒） |
| 拖到工作区最右 / 最下边（距边 ≤8px） | **收起**：贴平边缘，换成 `watch`（右侧）/ `sleep`（下方）姿势 |
| 收起后点一下 / 拖离边缘 56px | **展开**：就地在边缘站起来（位置不动），恢复 `idle` 与正常行为 |
| 隐藏（菜单） | 窗口完全藏起来，恢复靠托盘「显示桌宠」 |

收起与隐藏时她是**安静**的：不主动冒泡、感知提醒不发生；你自己点菜单要她说话时，她会先就地展开再开口。
她的日常说话只在她**闲着**（在播 `idle` 或收起的默认姿势）时才发生。

### 3.2 托盘 / 右键菜单

```text
（顶部读数）心情 / 饱腹 / token / 场景与在场 / 记得的经历 / 未看的小纸条
显示桌宠 / 隐藏桌宠
收起（贴边）            ← 勾选项；收起后变成「展开（恢复互动）· 当前右侧收起」
────────
交互…（N 条新的）        ← 收件箱 + 日记
────────
播放动画（测试）         ← 28 条动画逐条试播
插件                    ← 插件注册的动作 + 一行一个启停开关
────────
设置… / 退出
```

### 3.3 设置窗口

顶部是**桌宠大小**滑块（20%~250%，实时生效）与「恢复默认大小」「打开配置目录」「重载插件」；下面四个面板：

- **AI 认知与人格**：总开关、对话 / 记忆 / 情绪 / 日记四个子开关、人格设定与称呼、服务商与模型、
  token 预算、余额口径、情绪读数与「重置情绪」。
- **环境与用户感知**：感知状态、屏幕 / 行为 / 摄像头 / 习惯四个开关、隐私与隐私模式、
  采样与频率（含 GPU 过热阈值）、摄像头授权、习惯画像、「看我在做什么」、时间线、感知日志。
- **成长、记忆与反思**：记忆宫殿节点、今天的反思与历史、反思开关与时间、策略叠加层与「重置策略」、记忆日志。
- **插件**：已装插件卡片（启停 / 权限 / 卸载）、「安装插件…」、「重载插件」。

### 3.4 聊天窗口

三个页签 + 插件页签：

- **聊天**：打字对话的唯一入口；顶部状态条显示模式（已接入大模型 / 本地兜底）、心情、饱腹、token；
  「让她说句话」按钮。她说的话也会出现在桌宠头顶的气泡里。
- **交互**：收件箱（未读角标）、附件预览（文本 / 图片）、删除、打开目录。
- **日记**：按天看她的日记。
- **插件页签**：插件注册的界面（例如待办清单）。

## 4. 功能模块

### 4.1 动画系统

清单在 `assets/config/animations.json`（由 `tools/rebuild-manifest.mjs` 生成），渲染层不写死任何一条：

| 类别 | 数量 | 动画 |
| --- | --- | --- |
| 状态（默认姿势） | 3 | `idle`（正常）、`sleep`（下方收起）、`watch`（右侧收起） |
| 随机 | 11 | `roll` `hot` `play` `play_tail` `shake` `sing` `spin` `swim` `bomb` `peek` `lie` |
| 触发 | 11 | `catch_down` `catch_right` `hungry` `remind` `talk` `shy` `offline` `sad` `overheat` `read` `work` |
| 点击 | 3 | `cute` `fawning` `stroke` |

- **三段式**：`sleep` / `lie` / `watch` / `sad` / `overheat` / `read` / `work` 按
  `start → loop × N → end` 播放，`loop` 轮数每次在区间内随机（例如 `[2,5]`）。
  `loop` 期间被点击或被别的动画请求 → 先播 `end` 再播新动画；`end` 期间再被打断 → 立刻让位。
- **点击动画不可打断**（`interruptible: false`）：必须播完才接受下一次点击，期间的请求排队。
- **优先级与冷却**：每条素材自带 `priority` 与 `cooldown`；点击来源可绕过冷却，自动化来源受冷却约束。
- **随机小动作（正常状态）**：`normal-random` 池 9 条，间隔 25~60 秒、启动后先等 15 秒、
  池内冷却 8 秒，且只在她闲着时才演。
- **收起时的小动作**：下方收起 `lie`（3~8 分钟一次，循环 1~3 轮）、右侧收起 `peek`（3~8 分钟，1~2 轮）；
  触发时机是"默认姿势正在循环"，所以画面上是 `sleep(loop) → sleep(end) → lie×N → 回 sleep(loop)`。
- **心情过低**：正常状态的随机池整体换成 `sad`（默认 `mood < 25`）。
- **自愈**：视频层僵死（`readyState=0`）时看门狗会重载并接回默认动画。
- **素材**：黑底哑光用 ffmpeg 烘焙成带 alpha 的 VP9 WebM；播放器双缓冲换源，切换动画不闪。

### 4.2 行为与触发

随机行为、触发动画与冷却由渲染层的 `BehaviorManager` 与 `AnimationManager` 统一裁决；
阈值集中在 `src/shared/pet-triggers.ts`：

| 触发 | 条件 | 重新武装 / 冷却 |
| --- | --- | --- |
| `catch_down` / `catch_right` | 光标进入 150px，且下方 / 右侧占主导 | 离开 210px 重新武装；两次间隔 ≥ 60 秒 |
| `hungry` | 饱腹 ≤ 40 | 回到 ≥ 60 才重新武装 |
| `sad` | 心情 ≤ 25（随机池同时换成 `sad`） | 回到 ≥ 40 重新武装 |
| `offline` | 没配密钥 / 系统没网 / 请求连不上 / 密钥无效 / 余额不可用 | 好转后重新武装；坏状态持续时每 3~8 分钟随机再演一次 |
| `overheat` | `nvidia-smi` 温度 ≥ 阈值（默认 80℃，面板可改），回差 5℃ | 同上；读不到温度不触发 |
| `work` / `read` | 场景稳定 90 秒、不频繁切换、距上次同类 ≥ 20 分钟 | 场景变化重新计 |
| `remind` / `talk` | 感知干预 / 对话（受频率闸门与安静模式限制） | — |
| `shy` | 判定为私人内容 | 离开该场景后重新武装 |

### 4.3 AI 认知与人格（可关）

- **对话**：任意 OpenAI 兼容端点（DeepSeek / one-api / vLLM / Ollama…）—— `baseUrl` + `model` + `apiKey`。
  密钥只在主进程；端点不可用时降级成**本地兜底回复**（不联网，按情绪与关键词挑话）。
- **余额**：`GET /user/balance`（仅 DeepSeek 官方地址），30 分钟一次 + 启动一次；余额优先驱动饱腹度。
- **工具调用**：模型可调用 `recall_memory(query)` 去记忆宫殿检索相关经历（每条聊天最多 2 轮）。
- **记忆**（`data/memory/`）：长期事实 `profile.json`、流水 `events-*.jsonl` 与 `chat-*.jsonl`、
  前情摘要（`profile.json.summary`，每 6 轮滚动压缩）、记忆宫殿 `nodes.json` + `palace.md`。
- **情绪**：`mood`（0~100，互动上涨、不互动按在场状态衰减：正常 0.4/分、收起 1.0/分、隐藏 2.2/分；
  互动后 3 分钟只涨不跌）与 `satiety`（饱腹 0~100，100 = 很饱；优先由余额、否则由本地 token 预算推导）。
  两个状态会翻译成一段中文注入提示词，让她的语言与动画一致。
- **日记**：每天 `diaryHour`（默认 22 点）之后写一篇第一视角日记，当天有活动才写，漏掉的日子启动时补写。
- **主动闲聊**：主动开口的频率由既有闸门决定；说什么在多组候选间轮换（问候 / 今天的活动 / 最近的事 / 按习惯的询问）。
- **习惯建模**：把统计结果归纳成"她眼里的你" —— 作息由本地纯函数复算，总结与口语化的一句话交给模型写。

### 4.4 环境与用户感知（可关）

- **屏幕感知**：周期性截图（默认 30 秒，可调 5 秒~1 小时）交给视觉模型做**场景分类**，输出受控词表：
  写代码 / 读论文文档 / 看视频 / 打游戏 / 开会 / 浏览网页 / 聊天 / 写东西 / 命令行 / 没在动 / 私人内容 / 其他。
  同时截一条**地址栏横条**读网址，并读**窗口列表与最上层窗口**，三者一起判断场景。
  应用名与网址会做确定性纠正，用户也能在面板里写自己的纠正规则（`应用=场景`）。
- **行为观察**：系统空闲秒数、连续使用时长、最近一小时窗口切换次数、是否深夜、是否在电脑前。
- **主动干预闸门**：一分钟内不连说两次；免打扰时段（默认 23:00–08:00）不出声；用户不在 / 空闲不出声；
  每小时上限（默认 4 次）；两次之间最小间隔（默认 10 分钟）。敏感内容与"捂住眼睛"不受上限约束。
  收起 / 隐藏时进入安静模式，感知提醒整条不发生。
- **摄像头**（默认未授权）：显式授权后才取帧，用于判断在不在电脑前、表情、久坐、陌生人；
  画面只在内存里分析一次。
- **时间线**：观察记录按"同场景 + 同应用 + 间隔 ≤150 秒"合并成区间，落盘
  `data/perception/timeline-<日期>.json` 与 `daily-<日期>.md`；面板、聊天提示词与日记都读它。
- **习惯学习**：场景画像（"10 点你通常在写代码"）、行为信号、长期事实、反馈 → 反思 → 策略、
  经历与时间线、习惯模型六层；样本不足时不说，认不出来的场景当作没看见。
- **隐私模式**：一键停止一切采集（截图 / 摄像头 / 行为采样）。

### 4.5 成长、记忆与反思（可关）

- **记忆宫殿**：重要经历形成记忆节点并按时间轴组织，面板可视化、导出 `palace.md`，超期节点折叠归档；
  聊天时它作为工具 `recall_memory` 按需检索。
- **反思与策略**：每天一次（`reflectionHour` 后）复盘"我主动说了几次、有没有被回应、当时什么场景"，
  产出策略叠加层（`policy.json`）。策略只会让感知**更安静**（提高间隔、降低上限、按场景降权）。

### 4.6 交互收件箱

- 每条消息 = 发件人（她自己 / 某个插件 / 系统）+ 主题 + 正文 + 0..N 个附件 + 时间 + 已读未读。
- 类型：`她记的`、`记得的事`、`日记`（日记只写 `data/diary/`）、`收好的文件`。
- 附件会被**复制**进 `data/notes/files/`（源文件不动），可以预览文本、看图、删除整条。
- 在设置里选文件交给她收着（「收进小纸条」）；插件用 `mail` 权限投递生成的文件（例如 `todo.md`）。
- 文件内容由主进程读好再递给界面。

### 4.7 插件系统

- **权限**（在插件 `package.json` 里声明，静态可读）：`net` 联网 / `process` 起进程 / `python` 跑 Python /
  `notify` 系统通知 / `ui` 注册界面 / `mail` 投递收件箱；用户可以在 `assets/config/plugins.json` 里**收窄**。
- **接口**：动作与事件总线、动画请求、托盘 / 右键菜单项、聊天窗口自定义页签、本地存储、系统通知，
  以及按权限开放的联网 / 进程 / Python。
- **安装 / 卸载**：设置窗口「插件」→「安装插件…」（选一个插件文件夹，复制进 `plugins/<id>/`）→ 立刻启用；
  卸载会删掉目录、插件存储与 `data/plugins/<id>/`。
- **随时关闭**：托盘 / 右键「插件」子菜单里一行一个启停开关，点一下就生效。
- **随包插件**：`todo-plugin`（待办清单）—— 输入"时间 + 事件"，到点由桌宠提醒
  （气泡 + 系统通知 + `remind` 动画），可勾选 / 恢复 / 推迟 10 分钟 / 删除，能把清单导出成 `todo.md`
  投进收件箱，并在聊天窗口注册一个「待办清单」页签。权限：`ui` `notify` `mail`。
- 插件代码跑在沙箱里（blob ES module，无 Node / Electron 能力，无 `unsafe-eval`）。

## 5. 数据与配置

### 5.1 数据目录

默认 `<项目目录>/data`（项目目录不可写时退回 `%APPDATA%\DesktopPet`；可用环境变量
`DESKTOP_PET_AI_DATA_DIR` 覆盖，自动化验收用它隔离测试数据）。`data/` 已在 `.gitignore` 里。

| 目录 / 文件 | 内容 |
| --- | --- |
| `ai-settings.json` | 服务商、模型、**API Key**、预算、余额口径、人格与各子系统开关 |
| `emotion.json` | 当前心情与饱腹 |
| `memory/` | 长期事实、流水（事件 / 对话）、前情摘要、记忆日志、记忆宫殿 `nodes.json` + `palace.md` |
| `diary/` | 每天一篇日记 + `index.json` |
| `notes/` | 收件箱 `notes.json` + 附件 `files/` |
| `mood/` | 心情曲线采样（每 5 分钟一条） |
| `perception/` | 观察明细、时间线、习惯画像、习惯模型、感知日志、归档 |
| `reflection/` | 反思正文与策略叠加层 |
| `plugins/<id>/` | 插件自己的存储 |

日志不与记忆放在一起：仍在 `%APPDATA%\DesktopPet\logs\desktop-pet.log`（`npm run logs` 查看）。

### 5.2 配置文件

| 文件 | 作用 |
| --- | --- |
| `assets/config/animations.json` | 动画清单（28 条：素材、分类、优先级、冷却、三段式） |
| `assets/config/behavior.json` | 显示状态 → 默认动画 / 随机池 / 收起小动作；心情过低换池规则 |
| `assets/config/settings.json` | 桌宠尺寸、是否置顶、拖到边缘是否自动收起 |

| `data/*-settings.json` | AI / 感知 / 成长三块的运行期设置（设置面板改的就是这些） |

### 5.3 隐私边界

- 截图与摄像头帧**只在内存里分析一次，永不落盘**；观察记录只存文本。
- 网址默认只存域名（查询串不落盘）。
- 会离开这台机器的内容：聊天 / 日记 / 反思等提示词、截图与摄像头帧（如果开了）、余额查询。
- 渲染进程不能联网（CSP `connect-src 'none'`），也拿不到 API Key。

## 6. 架构

### 6.1 进程与目录

```text
src/
├── main/       主进程：窗口、托盘、IPC、AI、感知、成长、插件管理
├── preload/    唯一的桥：contextBridge 暴露 petAPI / settingsAPI / chatAPI
├── renderer/   桌宠窗口（动画与行为核心：AnimationManager / BehaviorManager / InteractionManager）
├── settings/   设置窗口（四个面板）
├── chat/       聊天窗口（聊天 / 交互 / 日记 + 插件页签）
└── shared/     主进程与渲染层共用的纯逻辑与类型（动画裁决、贴边几何、情绪、感知规则、笔记、时间线…）
```

安全基线：`nodeIntegration: false` + `contextIsolation: true` + `sandbox: true`；
素材走自定义协议 `pet-asset://`（只映射 `assets/`，拒绝路径穿越）。

### 6.2 事件总线

渲染层内部用类型化事件总线解耦：`pet:click` / `pet:dblclick` / `pet:drag` /
`animation:request|start|end|rejected` / `state:change` / `action:received|rejected` /
`plugin:*` / `behavior:triggered|paused` 等。插件通过 `context.events` 订阅同一套事件。

### 6.3 Action Pipeline

所有行为来源（用户 / 行为 / 插件 / 感知 / AI）都提交同一种 Action（animation / state / event），
由 `ActionManager` 统一校验并派发，校验与仲裁集中在一处。

### 6.4 状态机

`IDLE` / `PLAYING` / `SLEEPING` / `BUSY` 四个状态，白名单迁移，拒绝未知状态，保留迁移历史。

### 6.5 插件沙箱

插件代码由主进程编译成 ES module，在渲染进程里以 blob URL 执行；作用域内没有 Node / Electron 能力，
只能通过注入的 `PluginContext` 做事；某个插件抛错会被隔离并回滚它的订阅。

## 8. 技术栈

| 项 | 选择 |
| --- | --- |
| 运行环境 | Electron 33.4.11（Windows），Node 20 目标 |
| 语言 | TypeScript（strict，主进程与渲染层同仓） |
| 构建 | esbuild（主进程 / 渲染层 / 设置窗口 / 聊天窗口各打一份）+ 静态拷贝与插件编译脚本 |
| 界面 | 原生 DOM + CSS（无框架）：一个透明的桌宠窗口 + 设置窗口 + 聊天窗口 |
| 素材 | ffmpeg 烘焙 alpha 的 VP9 WebM |
| 打包 | electron-builder（NSIS 安装包 / 免安装目录） |
| 存储 | 本地 JSON / JSONL 文件（无数据库） |
| 大模型 | 任意 OpenAI 兼容 HTTP 接口（DeepSeek 官方地址额外支持余额查询） |
